# Analysis of a high throughput sequencing dataset

RNA-seq analysis of mouse lacrimal gland epithelium, control vs Pea3 TKO.\
Garg et al. (2018), PLoS Genetics - https://doi.org/10.1371/journal.pgen.1007660

## Dataset
- GEO: GSE114509 | BioProject: PRJNA471632 | SRA: SRP147008
- 6 samples, single-end, 4.71 GB
- Reference genome: GRCm39 (GCF_000001635.27)

## Structure
- `scripts/`: bash scripts, adapted from /data/bit09/scripts on the Sanger server
